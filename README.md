# HexEditor
HexEditor - simple hexadecimal editor.

### Documentation
HexEditor commands:

write - write value to list

read - print value from list at the index (index for ordinary python-list, ex. 0, 1...)

delete - delete value from list at the index (index for ordinary python-list, ex. 0, 1...)

print - print all values from list

save - convert all values from list to bytes, and save this bytes to file

exit - exit from program


### Information

For work HexEditor, need [Separation](https://github.com/Peach016/Separation).

HexEditor and Separation must be a one folder.
